A customized Astro Starlight theme for publishing docs and educational content.

## Prerequisites

- **Luau scripting knowledge**
- A roblox account and a baseplate of any types
:::tip
If you don't have one yet, you can follow the [**Creator Hub**](https://create.roblox.com/)
:::

## Installing the module

import { Steps, Tabs, TabItem } from '@astrojs/starlight/components'

<Steps>

1. Grab the LightBorn Kit from [**Github Releases**](https://github.com/Error-Cezar/LightBorn/releases)

2. Unpack `LightBorn` into the `ServerScriptService`

3. Start creating !

</Steps>
