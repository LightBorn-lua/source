Everything needs a start, this library included.

## Prerequisites

- **Luau scripting knowledge**
- A roblox account and a baseplate of any types
:::tip
If you don't have one yet, you can follow the [**Creator Hub**](https://create.roblox.com/)
:::

## Installing the module

import { Steps } from '@astrojs/starlight/components'

<Steps>

1. Grab the LightBorn Kit from [**Github Releases**](https://github.com/LightBorn-lua/LightBorn//releases)

2. Unpack `LightBorn` into the `ServerScriptService`

3. Start creating !

</Steps>
